# PDF document creator fonts

`DejaVuSans.ttf`, `DejaVuSans-Bold.ttf`, `DejaVuSans-Oblique.ttf`, `DejaVuSans-BoldOblique.ttf`, and `DejaVuSerif-Bold.ttf` are bundled for **server-side Unicode PDF rendering** in the portal document creator only.
